# Minggu 01 — Python Dasar

> **Padanan CS50:** Week 1 (C). Kita pakai Python sebagai pengganti C — sintaks lebih ramah pemula, fokus tetap pada konsep dasar pemrograman.

## Tujuan Pembelajaran
- Menjalankan program Python pertama (`print`, komentar).
- Memahami **variabel** dan **tipe data dasar**: `int`, `float`, `str`, `bool`.
- Menerima input pengguna (`input`) dan mengonversi tipe (`int()`, `float()`).
- Menggunakan **operator** aritmatika, perbandingan, dan penugasan.
- Memformat output dengan **f-string**.

## Konsep Kunci
- Sintaks dasar Python & indentasi.
- Variabel: penamaan, penugasan, mutasi nilai.
- Tipe data & konversi tipe (casting).
- Ekspresi vs. pernyataan (statement).
- Operator: `+ - * / // % **`, perbandingan, `and/or/not`.
- f-string & pemformatan angka.

## Lab Praktik
1. "Hello, world" lalu "Hello, <nama dari input>".
2. Kalkulator sederhana: jumlah, kurang, kali, bagi dua angka.
3. Konversi suhu Celcius ↔ Fahrenheit.

## Problem Set
- **PSet 1a:** Program menghitung indeks massa tubuh (BMI) dari input berat & tinggi.
- **PSet 1b:** "Mata uang" — konversi Rupiah ke USD/EUR dengan kurs tetap, output diformat rapi.

## Mini-Project
**"Tip Calculator"** — minta total tagihan dan persentase tip, tampilkan tip dan total akhir per orang.
