# Minggu 13 — AI Modern & LLM

> **Puncak jalur AI.** Mengenal intuisi neural network dan cara membangun aplikasi nyata di atas **Large Language Model (LLM)** seperti Claude.

## Tujuan Pembelajaran
- Memahami **intuisi neural network**: neuron, bobot, layer, training (tanpa matematika berat).
- Mengenal **deep learning** & untuk apa dipakai (gambar, teks, suara).
- Memahami konsep **LLM**: token, konteks, prompt, dan keterbatasannya (halusinasi).
- Membangun aplikasi sederhana memakai **API LLM** (mis. Anthropic Claude API).
- Mempraktikkan **prompt engineering** dasar & pemakaian AI yang bertanggung jawab.

## Konsep Kunci
- Dari ML klasik ke neural network & deep learning.
- Representasi: embedding & token (sekilas).
- Cara memanggil API LLM dari Python (request, prompt, response).
- Prompt engineering: instruksi jelas, contoh, konteks.
- Etika & batasan: halusinasi, bias, privasi data, sitasi.

## Lab Praktik
1. Demo intuisi neuron: bangun perceptron sederhana dari nol (NumPy) untuk klasifikasi linear.
2. Panggil API LLM dari Python: buat "tutor CS" yang menjawab pertanyaan.
3. Bandingkan beberapa prompt untuk tugas yang sama, amati perbedaan kualitas jawaban.

## Problem Set
- **PSet 13a:** Bangun chatbot CLI sederhana di atas API LLM dengan "kepribadian" tertentu.
- **PSet 13b:** Tulis esai singkat: kapan memakai ML klasik vs LLM, dan apa risiko etis tiap pendekatan.

## Mini-Project
**"Asisten Belajar AI"** — aplikasi (CLI atau Flask) yang memakai LLM untuk membantu meringkas materi kuliah atau membuat soal latihan, dengan prompt yang dirancang rapi.
