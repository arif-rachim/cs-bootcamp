# Minggu 03 — Fungsi & Abstraksi

> **Padanan CS50:** Week 1. Fungsi adalah cara utama membangun program besar dari potongan kecil yang dapat dipakai ulang.

## Tujuan Pembelajaran
- Mendefinisikan dan memanggil **fungsi** sendiri (`def`).
- Memahami **parameter, argumen, dan nilai kembalian** (`return`).
- Memahami **scope** (lokal vs global) dan kenapa global sebaiknya dihindari.
- Memecah masalah besar menjadi fungsi-fungsi kecil (**dekomposisi**).
- Mengenal Git dasar: `init`, `add`, `commit`, `push` (mulai membiasakan).

## Konsep Kunci
- Anatomi fungsi: nama, parameter, body, return.
- Argumen posisional vs. keyword; nilai default.
- Scope variabel & lifetime.
- DRY (Don't Repeat Yourself) & single responsibility.
- Pengenalan Git & GitHub untuk menyimpan pekerjaan.

## Lab Praktik
1. Ubah kalkulator Minggu 01 menjadi fungsi `tambah`, `kurang`, dll.
2. Fungsi `is_prime(n)` yang mengembalikan boolean.
3. Refactor: ambil kode berulang dari proyek sebelumnya jadi fungsi.

## Problem Set
- **PSet 3a:** Kumpulan fungsi utilitas: `faktorial(n)`, `fibonacci(n)`, `reverse_string(s)`.
- **PSet 3b:** Inisialisasi repo Git, commit semua latihan minggu ini, push ke GitHub.
